Formula 1, as a dataset.

Pick a season, event and session above. Every view is backed by a documented endpoint, so anything you see can be pulled into a notebook through the API or downloaded as CSV / Parquet from the Data Lab.

  • Pace statistics: distributions, dispersion, Welch / Mann-Whitney / KS tests, bootstrap CIs
  • Tyre models: fuel-corrected degradation with per-stint OLS and within-stint fixed effects
  • Telemetry: speed, throttle, brake, gear and RPM traces, delta time, braking zones
  • Track maps: mini-sector dominance and channel heat maps
  • Data Lab: a model-ready lap feature table, correlation matrix and scatter explorer
  • Championship: standings and round-by-round points progression

The first load of a session downloads the official timing feed (30–90 s). After that it's cached on disk.
